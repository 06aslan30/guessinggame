# Guessing Game

This is a simple guessing game written in Bash, where the user tries to guess the number of files in the current directory.
The game will continue prompting the user until they guess the correct number of files.

## How to Run

1. Clone this repository:
   `git clone https://github.com/06aslan30/guessinggame.git`

2. Navigate to the project directory:
   `cd guessinggame`

3. Make the guessinggame.sh script executable:
   `chmod +x guessinggame.sh`

4. Run the game:
   `bash guessinggame.sh`

The script will ask you to guess the number of files in the current directory. It will keep prompting you until your guess is correct.
